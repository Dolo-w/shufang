计算方法

成本公式很简单：每月成本 = (输入 token × 输入单价 + 输出 token × 输出单价) × 调用次数 ÷ 1,000,000。输入输出按各家官方「每百万 token」定价分别计价——输出价通常是输入价的 3~5 倍，所以账单大头一般是你生成的部分，不是你发送的部分。

统一口径：人民币定价按 ¥7 = $1 折算为美元展示，原币价格同时列出。表中为列表价，未计入 Batch 批处理（行业普遍 5 折）与 Prompt Caching 缓存命中（普遍降至原价 5%~10%）的折扣——如果你的场景能用上这两项，实际账单还能明显更低；DeepSeek 另有夜间空闲时段半价。

常见问题

token 是什么，怎么估算？

token 是大模型计量的最小文本单位，大约 1 个汉字 ≈ 1~1.5 token，4 个英文字符 ≈ 1 token。精确数量以各厂 API 返回的 usage 字段为准，本页估算仅作预算参考。

为什么输出比输入贵？

生成文本的计算量远大于读入文本：每个输出 token 都要对全部上下文做一次完整推理。行业惯例输出价为输入价的 3~5 倍，控制输出长度是最直接的省钱手段。

有哪些通用折扣可以叠加？

几乎所有厂商提供两项：Batch 批处理接口统一约 5 折（适合离线任务）；Prompt Caching 把重复发送的系统提示词等前缀降到原价 5%~10%（适合 Agent 与多轮对话）。此外 DeepSeek 工作日深夜空闲时段输入输出均约半价。
