一纸书房 · LLM 成本工具与国风测算

一纸书房是一组安静好用的在线小工具，主打 LLM API 成本计算与用量核对，数据来自各厂官方定价页，全部在浏览器本地计算，无需注册。

LLM 成本工具

  • LLM 成本计算器：输入 token 用量与调用次数，对比 GPT、Claude、DeepSeek 等主流大模型的 API 价格与每月成本，支持缓存命中率与 Batch 折扣。
  • 多轮对话成本模拟器：模拟 Agent 每轮重发上下文导致的账单滚雪球效应，查看缓存能省下多少费用。
  • LLM 用量对账器：粘贴 usage 或账单 CSV，按模型汇总 token 用量，核对账单差异并标出异常扣费。
  • LLM 价格变动史：追踪各家大模型 API 的涨价、降价与促销截止，只记录有官方出处的调整。

国风小工具

  • 一纸命笺：生辰干支五行命书生成。
  • 一纸日签：按生辰与今日干支出今日一签。
  • 一纸合婚：两人生辰合笺，看日柱合冲与五行互补。
